Pertanyaan yang Sering Ditanyakan

Tentang pendaftaran, server, biaya, dan pengelolaan toko mandiri.

Apakah Buat Toko Online Sendiri gratis?

Aplikasi toko online open-source ditujukan untuk penggunaan mandiri. Source code tersedia melalui GitHub. VPS, domain, dan layanan pihak ketiga memiliki biaya masing-masing.

Apakah saya perlu memiliki domain?

Tidak saat mendaftar. Domain dapat disiapkan ketika akan memasang dan mempublikasikan toko.

Apakah saya perlu VPS?

Aplikasi membutuhkan hosting/server yang kompatibel. Untuk instalasi awal, VPS Linux direkomendasikan.

Bagaimana cara memasang toko?

Mulai dengan mengisi pendaftaran. Materi panduan instalasi sedang disiapkan dan akan tersedia menyusul. Platform tidak memasang aplikasi secara otomatis.

Apakah saya bisa mengubah nama dan tampilan toko?

Bisa, melalui fitur Dekorasi Toko setelah aplikasi berhasil dipasang.

Apakah ada komisi penjualan?

Platform tidak mengambil komisi platform. Biaya layanan pihak ketiga tetap mengikuti penyedianya.

Apakah pendaftaran membuat akun atau toko otomatis?

Tidak. Formulir hanya mencatat informasi pendaftaran. Kamu tidak perlu password, OTP, atau login seller pusat. Instalasi aplikasi dilakukan secara mandiri setelah panduan tersedia.
