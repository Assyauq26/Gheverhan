# Installation workspace design

Mode: Operate. Extend Buat Toko Online Sendiri's existing restrained dashboard vocabulary rather than introduce a marketing visual world.

The first viewport presents the installation list and the one primary action to register an intent. A desktop detail column becomes the next document section on mobile. Pairing confirmation is inline and names the device key and requested scopes; no unnecessary modal or decorative status metric. Errors and unavailable services stay above the task and offer a real retry.

Tokens: white surface `#ffffff`, quiet canvas `#f6f6f5`, ink `#181818`, secondary ink `#545454`, line `#dededb`, Buat Toko Online Sendiri red `#b3121a`, danger `#9d1720`, success `#216341`. System sans at 16px; body line height 1.55; headings 24/30px; 8px spacing base; 12px control radius; minimum control height 44px. Black primary buttons, red brand accent and semantic state text. No display animation; 160ms control feedback only.

States: server loading, unavailable authentication, no session, empty registry, pending action, real pair confirmation, offline/retry and expired session. Never infer health from last contact, pairing or HTTP200.
