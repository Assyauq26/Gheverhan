Panduan resmi penggunaan installer

Dari VPS kosong hingga toko online live

Ikuti panduan ini secara berurutan untuk memasang satu toko mandiri di server dan domain milik Anda. Estimasi waktu bergantung pada aktivasi VPS, DNS, koneksi internet, serta proses build.

Panduan ini mengikuti repository installer Buattokoonline. Pendaftaran pada platform tidak otomatis membuat VPS atau toko. Instalasi membutuhkan akses administrator server.

LANGKAH 01

Siapkan kebutuhan utama

  • Domain sendiri (contoh tokosaya.com) dengan akses pengaturan DNS.
  • VPS baru Ubuntu 24.04 LTS, minimal 2 vCPU, RAM kelas 2 GB, 12 GB ruang kosong. Disarankan SSD 40 GB agar tersedia ruang untuk OS, database, media, dan update.
  • Jika RAM di bawah sekitar 4 GB, installer membutuhkan swap aktif sekitar 2 GB.
  • Akses SSH, pengguna dengan sudo, dan port publik TCP 80/443.
  • Komputer dengan terminal (Windows PowerShell, macOS Terminal, atau Linux).
Gunakan VPS kosong: installer menolak port penting yang sudah dipakai serta instalasi/data lama yang tidak dikenali. Jangan menjalankannya di server produksi lain.
LANGKAH 02

Masuk ke VPS dan periksa spesifikasi

Dapatkan IP publik, username SSH, dan metode autentikasi dari penyedia VPS. Dari komputer:

ssh USER@IP_VPS

Ganti USER dan IP_VPS dengan milik Anda. Di terminal VPS jalankan:

cat /etc/os-release
nproc
free -h
swapon --show
df -h
sudo -v

Pastikan Ubuntu 24.04, sekurangnya 2 vCPU, RAM cukup, dan ruang kosong minimal 12 GB. Jika swap belum tersedia pada VPS 2 GB, minta bantuan administrator atau ikuti dokumentasi penyedia VPS untuk menambah swap secara aman.

Periksa firewall penyedia VPS dan sistem operasi: izinkan SSH hanya dari alamat yang dipercaya jika memungkinkan, serta HTTP 80 dan HTTPS 443 untuk publik. Jangan membuka port database 5432, port aplikasi internal, atau wizard 8787.

LANGKAH 03

Arahkan domain ke VPS

  1. Di panel DNS domain, buat record A untuk @ menuju IP_VPS.
  2. Opsional: tambahkan CNAME www menuju domain utama, jika didukung penyedia DNS.
  3. Hapus record A/AAAA yang bertentangan; jangan hapus MX/TXT email yang tidak terkait.
  4. Tunggu propagasi DNS. Anda dapat memeriksa dari komputer:
nslookup tokosaya.com 1.1.1.1
nslookup tokosaya.com 8.8.8.8

Hasil A harus mengarah ke IP VPS Anda. Saat wizard berjalan, domain dan HTTPS akan diverifikasi lagi secara otomatis.

LANGKAH 04

Unduh aplikasi dan jalankan installer

Di sesi SSH VPS, jalankan secara berurutan:

sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/Assyauq26/buattokoonline.git
cd buattokoonline
sudo bash install.sh

Installer memeriksa perangkat, menyiapkan Docker jika diperlukan, lalu memberi tautan wizard lokal. Proses build dapat berlangsung beberapa waktu. Simpan output kesalahan jika terjadi gagal; jangan menghapus volume database untuk mencoba ulang.

Jangan menjalankan perintah installer dari sumber yang tidak dikenal. Tinjau repository dan script terlebih dahulu jika VPS menyimpan data penting.
LANGKAH 05

Buka wizard melalui SSH tunnel yang aman

Biarkan installer berjalan di terminal VPS. Buka terminal kedua di komputer Anda dan jalankan:

ssh -L 8787:127.0.0.1:8787 USER@IP_VPS

Lalu buka alamat http://127.0.0.1:8787 pada browser komputer, sesuai petunjuk/token yang muncul di terminal installer. Wizard hanya melayani loopback lokal; jangan buka port 8787 ke internet atau bagikan tautan setup.

  1. Nama Toko: masukkan brand dan identitas toko.
  2. Hubungkan Domain: masukkan domain, periksa DNS, koneksi publik, dan sertifikat HTTPS tepercaya.
  3. Buat Admin: tentukan email dan password kuat untuk dashboard, lalu konfirmasi.
  4. Selesai: wizard mengunci proses setup pertama dan menampilkan tautan storefront serta dashboard.

LANGKAH 06

Periksa bahwa toko sudah online

  • Domain utama membuka storefront dengan HTTPS dan ikon gembok yang valid.
  • URL dashboard dari halaman selesai bisa diakses.
  • Admin dapat login dengan akun yang dibuat di wizard.
  • Tidak ada error 502/503, redirect berulang, atau sertifikat tidak dipercaya.
  • Halaman toko dapat dibuka lewat perangkat dan jaringan lain.
Jika semua lulus, aplikasi sudah online. Tetapi toko belum tentu siap menerima pesanan sampai pengaturan bisnis dan pembayaran/pengiriman selesai.
LANGKAH 07

Lengkapi pengaturan di dashboard seller

  1. Isi identitas, logo, deskripsi toko, dan alamat kontak.
  2. Atur dekorasi/tema lalu publikasikan perubahan tampilan.
  3. Buat kategori dan produk, harga, variasi, foto, serta stok nyata.
  4. Konfigurasikan rekening pembayaran manual yang didukung.
  5. Atur email pengirim/Resend dan verifikasi OTP registrasi pelanggan sebelum membuka pendaftaran publik.
  6. Periksa kebijakan privasi, syarat, dan informasi layanan pelanggan.

Toko baru sengaja dimulai tanpa produk, pesanan, pelanggan, atau kredensial J&T milik toko contoh.

LANGKAH 08

Aktifkan alur transaksi dengan aman

Masuk ke menu Pengiriman. Jika tersedia, gunakan ongkir manual sesuai konfigurasi yang telah dirilis; untuk J&T Express, masukkan kredensial seller sendiri, mapping wilayah resmi, alamat gudang, lalu lakukan tes tarif sesuai dokumentasi. Jangan aktifkan J&T bila tarif atau mapping belum valid.

  1. Uji daftar/login pelanggan menggunakan OTP email nyata.
  2. Buat produk uji dan alamat tujuan yang valid.
  3. Uji keranjang, checkout, penghitungan total, pembayaran, dan pesanan menggunakan skenario yang aman.
  4. Pastikan tarif pengiriman valid sebelum checkout diterima.
  5. Uji email notifikasi, tampilan mobile, dan akses dashboard.
  6. Setelah seluruh pemeriksaan lulus, umumkan domain toko kepada pelanggan.
Nama menu dan metode ongkir mengikuti versi aplikasi yang benar-benar terpasang. Fitur yang belum dirilis tidak otomatis tersedia hanya karena tercantum dalam roadmap.
LANGKAH 09

Jika instalasi belum berhasil

  • DNS gagal: pastikan A record benar dan tidak ada A/AAAA konflik; tunggu propagasi.
  • HTTPS gagal: pastikan port 80/443 dapat diakses dari internet dan DNS mengarah ke VPS.
  • Wizard tidak terbuka: pastikan SSH tunnel masih aktif dan akses melalui 127.0.0.1:8787, bukan IP publik.
  • RAM/swap/disk kurang: periksa free -h, swapon --show, df -h lalu penuhi persyaratan.
  • Port terpakai: gunakan VPS bersih; jangan mematikan layanan yang tidak dikenal.
  • Checkout tertahan: periksa konfigurasi pengiriman dan tarif valid, bukan menonaktifkan pemeriksaan keselamatan.

Baca panduan pemulihan operasional dan sertakan pesan error yang sudah disamarkan saat meminta bantuan.

LANGKAH 10

Backup, pembaruan, dan keamanan berkala

Cadangkan database dan media di lokasi terpisah, uji prosedur pemulihan, pantau kapasitas disk, dan perbarui keamanan OS. Untuk memeriksa update aplikasi dari direktori repository:

sudo bash update.sh --check

Jika ada versi stabil kompatibel, baca catatan rilis dan backup terlebih dahulu. Terapkan versi spesifik sesuai petunjuk resmi:

sudo bash update.sh --apply --version VERSI_RILIS

Ganti VERSI_RILIS dengan versi yang benar-benar tersedia. Jangan menjalankan angka contoh sebagai versi nyata. Lihat dokumentasi update dan backup.

Checklist akhir: toko siap diumumkan?

  • Domain dan HTTPS valid
  • Admin bisa login
  • Produk, foto, harga, dan stok benar
  • Rekening dan metode pembayaran terkonfigurasi
  • OTP email berhasil diuji
  • Pengiriman dan ongkir valid
  • Checkout end-to-end berhasil diuji
  • Backup serta pemulihan siap
