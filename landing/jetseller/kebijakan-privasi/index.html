Kebijakan Privasi Pendaftaran

Versi 2026-11-05.1 · Berlaku 5 November 2026

Buat Toko Online Sendiri menyimpan data yang kamu kirim untuk mencatat pendaftaran, memahami kebutuhan toko, dan menghubungi kamu terkait layanan yang diminta. Formulir tidak membuat akun atau menginstal toko.

Data yang disimpan

Nama lengkap, email, nama brand, kategori produk, serta WhatsApp, domain, kota/kabupaten, dan deskripsi bila diisi. Kami juga menyimpan nomor referensi acak, waktu pendaftaran, serta waktu dan versi persetujuan privasi.

Keamanan dan penggunaan

Data disimpan pada PostgreSQL platform yang terpisah dari database toko demo. Tidak ada daftar pendaftar publik. Kami tidak meminta password, OTP, API key, atau akses VPS. Tidak ada cookie akun seller atau penyimpanan formulir di localStorage. Formulir tetap berada di memori tab selama berpindah langkah; menutup atau memuat ulang tab menghapus isian yang belum dikirim.

Untuk mencegah spam, layanan memakai challenge formulir dan pembatasan permintaan. Alamat IP diproses sementara dan diubah menjadi pengenal HMAC sebelum disimpan sebagai penghitung. Penghitung disimpan paling lama 48 jam; challenge kedaluwarsa setelah 30 menit. Log layanan tidak merekam isi formulir. Server infrastruktur tetap memproses koneksi untuk melayani situs.

Penyimpanan dan akses

Data pendaftaran disimpan selama diperlukan untuk tindak lanjut layanan, dengan peninjauan paling lambat 12 bulan setelah pendaftaran. Akses dibatasi untuk operator berwenang. Penyedia infrastruktur memproses data untuk menjalankan layanan. Data tidak dijual dan tidak digunakan untuk kampanye pemasaran tanpa persetujuan terpisah.

Koreksi dan penghapusan

Hubungi m.rifatsyauqii@gmail.com dari email pendaftaran dengan subjek “Privasi BTOS” untuk meminta akses, koreksi, atau penghapusan. Sertakan nomor referensi bila ada; jangan kirim password atau dokumen sensitif. Operator memverifikasi kepemilikan email sebelum memproses permintaan.

Penghapusan dilakukan pada data aktif dan daftar pemulihan backup. Backup terenkripsi tidak dipakai untuk operasional; bila dipulihkan, permintaan penghapusan diterapkan kembali sebelum layanan dibuka.

Toko mandiri

Database, pelanggan, dan media toko yang dipasang pada server sendiri berada di bawah pengelolaan pemilik toko. Pendaftaran di sini tidak memberikan akses platform ke server atau database tersebut.
