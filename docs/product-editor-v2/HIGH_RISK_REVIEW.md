## Kontrol dan bukti bersama
Braces parser/compile/expand/stringify dan traversal AST dibatasi depth128 melalui patch baseline dengan SHA-256/source guards. Unknown source/hash/version gagal tertutup. Build/lint menjalankan security:prepare; wrapper unit verify-only dan offline read-only containment. Sembilan mitigation tests mencakup nested brace/parenthesis, malicious AST, globs normal, semua installed copies dan modified-source refusal. Tidak mengirim input HTTP pelanggan ke compiler glob pada jalur aplikasi yang ditelaah. Beberapa packages non-dev dalam lockfile: tidak menganggap semuanya dev-only.
Residual: raw npm package tetap vulnerable sebelum prepare, build/config glob yang tidak dipercaya tetap tidak boleh dijalankan di luar profil hardened, dan dependency upgrade harus mereview ulang guard. Aplikasi/CI lain yang tidak memakai source guard tidak tercakup. Patch lokal bukan upstream patched version atau izin menerima risiko.
